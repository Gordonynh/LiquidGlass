# 液态玻璃

把 ClassIsland 状态栏换成苹果液态玻璃（Liquid Glass）质感。

## 不是又一个毛玻璃

常见的「玻璃拟态」实现只有两步：背景模糊 + 一层白色半透明。那样出来的是**贴纸**，
不是玻璃 —— 没有厚度、没有曲率，边缘是一条等宽的死线。

这个插件把玻璃当作一块**有厚度的实体**来算。所有边缘效果都从圆角矩形的
有向距离场（SDF）推导：

| 层 | 作用 |
|---|---|
| 接触投影 | 两道：宽的软投影给纵深，1 像素的接触投影让底边「落」在东西上 |
| 折射背景 | 把视线折进玻璃，再投到虚拟背景平面上取色 |
| 散射 | 光穿过玻璃厚度时的散射。少了它折射内容全锐，像哈哈镜不像材质 |
| 动态范围压缩 | 背景很花时把对比压向均值，保证条上的字压得住 |
| 染色 | **按背景亮度索引**的色阶，不是糊一层白 |
| 内侧暗边 | 紧贴亮边的里侧压一道暗，亮暗相邻才有厚度 |
| 镜面高光 | 贴边的亮弧，两盏对向光；颜色取自背景，不是自己发白光 |
| 菲涅耳边缘 | 法线越接近掠射越亮 |
| 边缘色散 | 红蓝在边缘错开极小的一点 |

形状本身也讲究：圆角用 **L⁴ 超椭圆**而非正圆（正圆在圆角接直边处曲率不连续，
高光弧上会出现肉眼可见的折角），厚度剖面用 **squircle** 而非四分之一圆
（圆形剖面在拱面接平面处留接缝，拉成长条时非常明显）。

整条管线跑在 GPU 上：一趟裁剪、两趟可分离高斯、一趟统计（靠 mipmap 逐级平均，不回 CPU）、
一趟主绘制，约 0.3 毫秒一帧。

**边缘的位移故意大于带宽。** 纯物理的 Snell 折射在倒角上位移峰值只有带宽的 0.23 倍，
数学上恒小于带宽，映射必然单调，边缘只能是一层软渐变——这是多数复刻看起来偏弱的原因。
苹果那一层不是折射，是屏幕空间的非物理重映射，位移被故意设得大于带宽。这里照此处理，
位移默认取带宽的 1.6 倍（可调）。

## 折射需要背后的像素

这是决定它像不像玻璃的唯一一件事，也是使用上唯一需要权衡的地方。

状态栏是置顶的，背后的内容不在本程序的画布里。插件用 **DXGI 桌面复制**取 DWM 合成后的整屏，
所以背后是壁纸、是课件、还是别的窗口，一律照实折射。

代价是必须给 ClassIsland 的窗口设 `WDA_EXCLUDEFROMCAPTURE`，否则每帧都在折射上一帧的自己。

> ⚠ **这会让状态栏在 Zoom、腾讯会议、OBS 和投屏里看不见。**
> 要录课或投屏就在设置里把折射关掉——关掉之后只剩玻璃外壳，也不再捕获任何东西。

桌面复制拿的是显存里的纹理，全程没有 CPU 访问：`CopyResource` 是显存到显存，
着色器直接采样，结果写进共享纹理交给 Avalonia，像素一次都没有进过内存。

## 与像素流动共存

本插件**只替换状态栏那块背景板**，不碰任何控件模板。通知那一整套仍归像素流动管，
两个插件互不干涉：平时是玻璃，来通知时是像素流动。

> ⚠ 主题按启用顺序依次叠加，后加的覆盖先加的。
> 要两个都生效，「液态玻璃」必须排在「像素流动」**之后**启用。
> 设置页会检查顺序，不对会提示。

## 文字随背景自动反黑白（默认关）

逐像素判定文字该用黑还是白，阈值取 WCAG 的交叉点 Y\*=0.179128
（对黑与对白的对比度相等的那个亮度），在它两侧判定能把最差情况的对比度顶到最高。

**默认关，因为它依赖的能力并非处处可用。** 这条链要求 `RenderTargetBitmap` 能画出字形，
而部分虚拟 GPU 上画得出形状、画不出字形。插件会自己数掩膜里的有效着墨，
低于 2% 就判定不可用并恢复原文字——宁可没有自适应，也不能让状态栏变成一条空白。
着墨百分比写在插件配置目录的 `status.txt` 里，开之前可以先看一眼。

## 启用后的两点变化

- **主界面透明度不再影响状态栏。** ClassIsland 把这块背景板的不透明度绑在「主界面透明度」上；
  玻璃必须画成不透明的，否则背后的真实画面会直接透过来，和折射出来的副本叠成重影。
- **界面缩放会被正确计入。** 缩放不等于 1 时，按控件逻辑尺寸分配纹理会导致折射内容整体放大并偏移，
  所以插件拿控件两角各做一次 `PointToScreen` 来量实际覆盖范围。

## 多屏与失效恢复

- 桌面复制是**按显示器**的，交出来的纹理坐标从那台显示器自己的左上角算起。
  插件按状态栏所在的那块屏挑显示器；状态栏被挪到另一块屏上会自动重挑。
- 切换全屏程序、改分辨率、DWM 重启、锁屏回来都会让复制失效。
  失效后一律判定作废并在下一帧重建，不会停在失效前的那一帧。
- 排除捕获的标志会被宿主在窗口激活时冲掉，所以每帧回读一次、失效就补设。

## 设置

应用设置 → 液态玻璃。可调边缘厚度、位移量、高光强度、光源方向、色散、染色，
以及折射与文字自适应两个开关。

排查问题的落脚点是插件配置目录下的 `status.txt`：每 900 帧记一行，
含控件尺寸、缩放、屏幕位置、实测到的宿主不透明度、所在显示器与其矩形、桌面纹理尺寸、裁剪原点。
状态栏被排除在屏幕捕获之外，截屏拍不到它，所以现场只能靠这个文件说话。

## 说明

- 仅 Windows，需要 D3D11
- ClassIsland 落到软件渲染时（虚拟机、远程桌面、驱动异常）自动降级成
  「只有玻璃外壳、没有折射」，不会崩
